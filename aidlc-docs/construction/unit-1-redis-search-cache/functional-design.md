# Functional Design — Unit 1: Redis Search Cache Repository & Backend Adapter

## 1. Overview
Provides high-performance, Redis-backed search caching with 7-day TTL (`604800s`) to avoid redundant web search calls and reduce LLM token usage across research jobs for the same company.

## 2. Interface Specification
```python
class RedisSearchCacheRepository:
    def __init__(self, client: redis.Redis | None = None, async_client: aioredis.Redis | None = None) -> None: ...
    def get_search(self, company_name: str, query: str) -> dict[str, Any] | None: ...
    async def async_get_search(self, company_name: str, query: str) -> dict[str, Any] | None: ...
    def set_search(self, company_name: str, query: str, results: Any, domain: str | None = None, ttl_seconds: int | None = None) -> bool: ...
    async def async_set_search(self, company_name: str, query: str, results: Any, domain: str | None = None, ttl_seconds: int | None = None) -> bool: ...
    def get_searches_for_company(self, company_name: str) -> list[dict[str, Any]]: ...
    async def async_get_searches_for_company(self, company_name: str) -> list[dict[str, Any]]: ...
    def get_cached_query_hashes(self, company_name: str, hashes: list[str]) -> set[str]: ...
    async def async_get_cached_query_hashes(self, company_name: str, hashes: list[str]) -> set[str]: ...
    def count_searches(self, company_name: str) -> int: ...
    async def async_count_searches(self, company_name: str) -> int: ...
```

## 3. Storage Format
- **Key Pattern**: `search:{company_key}:{query_hash}`
- **TTL**: 7 days (`EX 604800`)
- **JSON Payload**:
  - `company_name`: Target company name
  - `company_key`: SHA-256 hash prefix (16 chars)
  - `query`: Executed search query
  - `query_hash`: SHA-256 hash prefix (16 chars)
  - `domain`: Research domain
  - `results`: Search snippets, titles, URLs, and webpage content
  - `cached_at`: UTC timestamp (ISO 8601)
  - `expires_at`: UTC timestamp (ISO 8601)
